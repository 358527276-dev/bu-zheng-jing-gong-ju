# 🤪 不正经工具箱

一个让8000万人上头的一元AI趣味工具站。

## 🚀 快速开始

1. 双击 `启动服务.bat`
2. 浏览器打开 http://localhost:3000
3. 开始玩！

## 📍 重要地址

| 页面 | 地址 | 默认密码 |
|------|------|----------|
| 用户端 | http://localhost:3000 | - |
| 管理后台 | http://localhost:3000/admin.html | admin123 |

## 📁 项目结构

```
不正经工具箱/
├── frontend/          # 前端代码（HTML/CSS/JS）
│   ├── index.html     # 用户端首页
│   ├── admin.html     # 管理后台
│   ├── css/           # 样式
│   ├── js/            # 脚本
│   └── images/        # 图片（收款码在这里）
├── backend/           # 后端代码（Node.js + Express）
│   ├── server.js      # 服务入口
│   ├── db.js          # 数据库操作
│   ├── aiService.js   # AI服务（千问/豆包）
│   └── data/
│       └── db.json    # 数据库文件（备份就拷这个）
└── 启动服务.bat        # 一键启动脚本
```

## ⚙️ 配置修改

打开 `启动服务.bat`，修改配置区：

```bat
set ADMIN_PASSWORD=你的后台密码
set AI_API_KEY=你的千问APIKey
set AI_MODEL=qwen-turbo
```

## 💰 收款码替换

把你的微信/支付宝收款码图片放到：
```
frontend/images/qrcode-wechat.jpg   (微信收款码)
frontend/images/qrcode-alipay.jpg   (支付宝收款码)
```
文件名不要改，直接覆盖就行。

## 💾 数据备份

数据库就是一个文件：`backend/data/db.json`
定期复制这个文件到别的地方就行。
